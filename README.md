## 🚀 Featured Projects

### 🔹 Real-Time Traffic Detection with YOLOv8

A complete desktop application for real-time traffic monitoring and lane-based traffic analysis using Python, OpenCV, and a custom-trained YOLOv8 model.

This system detects vehicles from traffic videos, counts vehicles per lane, visualizes traffic density with green/yellow/red lane colors, saves processed videos, generates Excel reports, and provides separate Admin and System Manager panels.

**Highlights:**

- Custom-trained YOLOv8 vehicle detection model
- Lane-based traffic density analysis
- Admin and Manager dashboard
- Processed video output
- Excel report generation
- Activity logging
- PyInstaller executable build
- Independent from Google Maps or external traffic APIs
